# Установка и настройка mws cli

Если у пользователя не найдена утилита `mws cli`, предложи ему установить ее. В случае положительного ответа, используй команду ниже, в зависимости от ОС.

## macOS/Linux

```shell
curl -sSL https://storage.mwsapis.ru/mws-cli/install.sh | bash
```

## Windows

```shell
iex (New-Object System.Net.WebClient).DownloadString('https://storage.mwsapis.ru/mws-cli/install.ps1')
```

## Инициализация профиля

Если профиль не инициализирован, предложи пользователю выполнить `mws init`:

- По умолчанию аутентификация проходит через OAuth в браузере; если браузер недоступен — флаг `--no-browser` (пользователь откроет ссылку и введет код)
- Неинтерактивно по авторизованному ключу сервисного аккаунта: `mws init --service-account-authorized-key <путь к файлу ключа>`
- На виртуальной машине MWS Compute можно использовать привязанный к ней SA: `mws init --vm-sa`
- `--project` и `--zone` задают проект и зону по умолчанию; если профиль единственный, он активируется автоматически
- Существующий профиль не перезаписывается без подтверждения; для принудительной перезаписи — флаг `--force`
