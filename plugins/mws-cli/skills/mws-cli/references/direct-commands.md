# Команды mws cli

- Если пользователь явно попросил вызвать конкретную команду утилиты `mws`, вызови ее.
- Если пользователь попросил вывести ему команду утилиты `mws` для решения его проблемы, проанализируй help, составь правильную команду и выведи ее пользователю, но **НЕ ВЫЗЫВАЙ**.
- Если пользователь запросил токен, используй команду `mws iam create-token`.
